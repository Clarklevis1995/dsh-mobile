桌面准备好，
扫码就能继续。

先安装 DeepSeek Harness 桌面端并配置模型服务，再按照下面的图文安装网关插件、配对手机。

下载官方桌面端 ↗ 查看网关插件文档 ↗

从桌面端的“插件”开始。

安装好 DeepSeek Harness Desktop 后，点击左侧栏上方的“插件”，进入插件列表。

添加移动网关插件。

在插件列表右上角点击“添加插件”，输入下面的包名，然后点击“安装”，等待安装完成。

dsh-plugin-mobile-gateway

确认插件和组件都已开启。

打开已安装的 dsh-plugin-mobile-gateway，确保插件总开关与 mobile-gateway 组件开关开启，并确认组件显示“运行中”。

安装或更新后如果连接异常，请完全退出并重启桌面端；端口仍被占用时，关闭其他 Harness 实例。

打开“移动设备”控制面板。

点击桌面端左下角的“移动设备”。在“通用设置”中开启移动网关，并保持“设备鉴权”开启；可将网关运行模式设为“常驻开启”。

选择手机能访问的连接方式。

进入“连接与配对”。手机和电脑在同一 Wi-Fi 下，选择“局域网直连”；需要外网连接时，先开启 Quick Tunnel 并等待连接成功，再选择“Cloudflare 外网”。

截图中的局域网地址属于示例电脑。实际配对时，请使用你自己的网关地址。

生成你自己的二维码，再扫码。

点击“生成配对二维码”。打开手机上的 Whaleness，选择“扫描二维码”，扫描自己桌面端弹出的二维码。连接成功后，即可选择工作区、查看会话或创建新任务。

配对码仅可使用一次，五分钟内有效。Quick Tunnel 地址变化后，需要重新生成二维码并扫码。

开始之前，你可能想知道。

Whaleness 是 DeepSeek 官方应用吗？+

Whaleness 是独立开发的 DeepSeek Harness 第三方移动端应用，与 DeepSeek 官方没有隶属关系。

手机可以单独使用吗？+

需要先连接运行 DeepSeek Harness 与移动网关插件的电脑或服务器。模型服务与任务执行环境在主机上配置。

离开家里的 Wi-Fi 后，还能连接吗？+

可以使用网关插件支持的 Cloudflare Tunnel 等外网连接方式。使用 Quick Tunnel 时，地址可能在重启或重连后变化，需要重新生成配对二维码。
