## 功能更新

- 新增文件改动预览，输入框上方显示文件数和增删统计；支持切换文件、换行图标、绝对路径跳转完整预览，以及手机和平板布局。改动记录不可用时自动隐藏入口。
- 新增设备连接器与能力状态页，可按授权让 Agent 使用手机的日历、提醒、位置、照片与音乐等能力，并按平台提供系统闹钟等操作。
- 新增地图与音乐卡片，地图支持选择已安装的地图应用打开路线，保留网页地图入口。
- 适配 DSH 0.2.2-rc.3 的智能体团队，支持在会话菜单启用团队协作，改善多层子代理目录、任务负责人定位及任务筛选。
- 用户消息支持 Markdown 渲染，优化数学公式、代码、表格及长文本的排版和文字选择，并增加对话时间分隔。
- 改善 Android 后台常驻与电池限制提示，修复 iOS 录音启动异常处理，优化连接及会话交互的稳定性。
- 修复文件预览关闭时误报加载失败、菜单弹出位置偏移、Android 底部面板贴顶及平板会话列表留白问题，统一双端预览样式。

## 必需插件

- 必须安装 [dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway) `v0.12.1` 或更高版本。
- 安装或升级后，需要完整退出并重新启动 `dsh web`。

```bash
dsh plugin --profile web add dsh-plugin-mobile-gateway@latest
```
