## 功能更新

- 双端新增系统分享接收，支持将其他应用的链接、图片和文件带入会话草稿，不会自动发送。
- iOS 支持系统分享中的最近会话建议，普通分享入口可直接创建默认工作区草稿；Android 新增分享面板，支持跨工作区选择、会话搜索、最近进行中会话直达和内容预览。
- 新会话支持在输入区切换工作区，并保留尚未发送的草稿与附件。
- 完善双端英文界面、错误提示和实时活动文案，修复 iOS 切换应用语言影响系统键盘语言、实时活动步骤重复显示的问题。
- 改善 Markdown 正文、表格及文件预览中的图片显示、缩放与保存，修复相对路径图片加载和跨会话缓存问题。
- 优化 iOS 会话列表和长对话加载，减少停止滚动后的位置跳动、首屏等待及流式回复对阅读位置的干扰。
- 修复 Android 分享面板与会话状态面板的顶部错位，以及列表滑到边界时带动面板抖动的问题。
- Agent 输出时，双端输入框收起后仍保留停止按钮，可直接停止生成，并防止重复提交停止请求。
- iOS 26 及以上支持系统后台持续处理任务与进度展示，改善切到后台后的任务衔接。
- 修复子 Agent 会话的历史加载、订阅和停止请求未正确定位到子会话的问题。

## 必需插件

- 必须安装 [dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway) `v0.12.0` 或更高版本。
- 安装或升级后，需要完整退出并重新启动 `dsh web`。

```bash
dsh plugin --profile web add dsh-plugin-mobile-gateway@latest
```
