## 功能更新

- 双端新增代码语法高亮，优化代码卡片、语言标识和复制操作；长代码保留缩进并支持横向滚动。
- iOS 聊天正文新增行内和独立数学公式显示，改善文字选择及复制时的公式处理。
- 改善双端聊天、工作区和执行轨迹之间的横滑导航、顶部玻璃效果及侧栏交互；Android 会话侧栏支持按工作区分组浏览。
- 修复 iOS 在文字模式进入聊天时仍可能预热录音会话、导致后台音乐暂停的问题；切回文字输入时及时释放录音资源。
- 语音输入新增录音时长与上限提示，达到上限后自动转文字。
- 优化聊天历史加载和增量更新，减少重复加载与界面停顿；修复 iOS 已离开会话的订阅超时仍弹出错误的问题。
- 改善执行轨迹总览，支持横向浏览和切换实际耗时比例；修复 iOS 表格预览旋转及部分横竖屏布局问题。

## 必需插件

- 必须安装 [dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway) `v0.11.1` 或更高版本。
- 安装或升级后，需要完整退出并重新启动 `dsh web`。

```bash
dsh plugin --profile web add dsh-plugin-mobile-gateway@latest
```
