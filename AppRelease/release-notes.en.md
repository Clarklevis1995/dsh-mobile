## What's New

- Both apps now preview images generated by tools directly in conversations. On iOS, you can retry failed image loads, with more reliable attachment recovery after switching sessions or reconnecting.
- iOS now loads the two most recent pages of conversation history together when you open a session. This fixes incomplete initial views of running sessions and repeated jumps as earlier messages load.
- Fixed messages being obscured when the iOS composer or task panel changes height. Improved navigation in Settings and the display of permission names.
- Android workspace files now support image, SVG, and video previews, as well as saving images.
- Added a **Reduce UI effects** setting on Android to stop home-screen background animations and reduce glass effects. Also improved the home screen and Settings layout.
- Recent sessions can now be expanded and collapsed on both platforms, making it easier to browse older sessions.
- Fixed a possible Android crash when exiting text selection in Markdown content.

## Required Plugin

- Install [dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway) `v0.11.3` or later.
- After installing or updating it, fully quit and restart `dsh web`.

```bash
dsh plugin --profile web add dsh-plugin-mobile-gateway@latest
```
