# Whaleness 产品宣传页

入口是仓库根目录的 `index.html`。沿用现有 GitHub Pages 的 `main / (root)` 发布方式，推送后对应 `https://clarklevis1995.github.io/dsh-mobile/`。隐私政策仍位于 `privacy/index.html`。

页面使用原生 HTML、CSS 和 JavaScript，不依赖构建工具或第三方 CDN。使用统一深海配色，支持手机布局、功能页签、截图放大、键盘导航和减少动态效果设置。

## 液态玻璃与深海动态背景

导航外壳、功能展示卡片、Agent 预设展示卡片、连接指南面板、两张下载卡片和弹窗外壳使用 Glasswork 液态玻璃材质，沿用原有尺寸、圆角、字体和文案。按钮、桌面截图和二维码内容保留实色，避免影响阅读与识别。

`styles.css` 定义唯一的蓝黑深海主题，网页不跟随系统明暗外观，也没有外观切换入口。`liquid-glass.css` 定义透明度下限、玻璃高光与无 WebGL 时的海洋背景回退。材质采用统一的默认参数，并保留文字可读性所需的最低遮罩。

`ambient-scene.js` 使用原创的真实水面纹理，呈现水下仰望海面的细碎折光、由上至下的穿透光与蓝黑深水层次。动态部分只做轻微画面浮动、水面反光叠加、光束明暗和少量颗粒，不逐帧计算复杂水面或运行像素噪声模拟。`liquid-refraction.js` 将同一帧背景送入 WebGL，文字、按钮与截图仍由正常 HTML 绘制；折射只作用于主卡片边缘，中央保持清晰。

水面纹理由内置 `image_gen.imagegen` 生成，参考用户提供图片的构图与氛围，没有直接复制参考图片。原图与完整提示词保存在 `output/liquid-glass/ocean-original-v1.png`、`output/liquid-glass/ocean-v1.prompt.txt`。网页分别使用 `assets/ocean-surface-v1.webp`（1440×960，约 73KB）、`assets/ocean-surface-medium-v1.webp`（960×640，约 33KB）、`assets/ocean-surface-small-v1.webp`（720×480，约 18KB）。

CSS 先加载 18KB 的静态海水图，再按性能档位选择一个尺寸供画布使用，异步解码后才启用画布。色调与可读性遮罩在加载、尺寸变化时一次性绘入缓存，缓存与背景画布各自遵守同一像素上限；不会逐帧解码图片或重新调色。场景销毁时清理图片回调与缓存画布。最低档与无 JS 环境只使用 CSS 静态海水图，不创建背景绘制循环。

设备预算允许且 WebGL 2 可用时，Chromium、Safari 和 Firefox 共用同一条折射路径；不依赖浏览器是否支持 `backdrop-filter: url()`。WebGL 不可用、上下文丢失或纹理上传失败时，直接降为轻量 2D 背景与简化卡片，不再尝试另一套昂贵的 SVG 位移滤镜。直接打开本地 HTML、模块加载失败或 JS 不可用时使用静态 CSS 深海背景。

粒子缓慢上浮并随水流横向漂移，出入画面时淡入淡出。光束使用预生成的柔边纹理；背景逐帧绘制不使用大范围模糊滤镜、像素读回或 `gl.finish()`。

### 资源预算

`render-budget.js` 集中定义资源上限。设备内存不超过 2GB 或 CPU 逻辑核数不超过 2 时直接使用静态档；内存不超过 4GB 或 CPU 逻辑核数不超过 4 时从轻量档启动；普通窄屏、触摸设备及硬件信息缺失时默认保守档。节省流量模式使用静态档。这些信号只是保守的启动依据，不能代替机型实测。

| 档位 | 背景帧率上限 | 背景画布像素上限 | WebGL 画布像素上限 | 粒子数 |
| --- | --- | --- | --- | --- |
| 完整 | 24 | 700,000 | 1,100,000，像素比最多 1 | 56 |
| 保守 | 18 | 360,000 | 480,000，像素比最多 0.85 | 26 |
| 轻量 | 12 | 220,000 | 不创建 WebGL 上下文 | 16 |
| 静态 | 不绘制 | 仅 CSS 图片，画布释放为 1×1 | 不创建 WebGL 上下文 | 0 |

同时限制画布长边，防止高 DPI、4K/8K 或超长视口放大缓冲。WebGL 请求低功耗上下文，不使用抗锯齿、深度或模板缓冲；纹理只在尺寸变化时分配，普通帧通过 `texSubImage2D` 更新。保守档停用色散的三通道采样；轻量与静态档停用卡片背景滤镜并简化阴影。

只有进入视口且完成入场动画的卡片参与折射；没有可见卡片时不执行 GPU 绘制。几何与样式只在滚动、布局变化后读取。滚动事件与背景动画共用帧截止时间，事件再密集也不会绕过帧率上限。窗口变化等待 180ms 稳定后再调整画布尺寸，期间使用现有背景，避免连续重新分配缓冲。

持续超时的绘制或帧间隔会自动逐档降级，最终切换至 CSS 静态背景并释放画布缓存；当前访问期间不自动升档，避免画质反复跳变。监测需要至少 24 个样本及 1.8 秒的持续压力，不会因单个长帧触发降级。

页面隐藏时清除绘制计时器；离开页面时释放 GPU 资源。弹窗打开时暂停背景流动。开启“减少动态效果”时只在需要时绘制静态背景，滚动仅更新折射位置、不重复上传背景纹理；开启“减少透明度”或强制颜色模式时释放画布缓冲与 GPU 资源并使用实色表面。

本地依赖位于 `vendor/glasswork/`，来源为 [kubai087/glasswork v1.1.0](https://github.com/kubai087/glasswork/tree/v1.1.0)，按 MIT 许可证使用，保留原许可证。`glass.css` 保留本页圆角与入场动画；`refract.js` 增加了缓冲尺寸限制、外部帧时钟、纹理复用和资源释放。`lens.js` 保留原版作为参考，不在页面中加载。

连接指南的截图按当前步骤加载，不再在进入网页时整批预加载后续截图。

预算策略单元测试：`node --test scripts/test_web_render_budget.mjs`。浏览器夹具在 `output/liquid-glass/budget-check.html`，用于模拟低内存、慢帧、密集滚动、窗口变化、后台页面和 GPU 失败；该目录为本地验证产物，不随站点发布。这些验证覆盖预算和回退行为，不能代替真实低端机的 GPU 驱动、温度与耗电实测。

验证覆盖 Chromium 与 Safari 27.0.1 的 WebGL 初始化、390px 窄屏渲染及背景帧更新。通过本地夹具模拟并检查了 WebGL 不可用、减少动态效果、减少透明度和强制颜色偏好，也触发真实的 WebGL 上下文丢失检查回退。滚动后折射区域定位和 JavaScript 语法检查通过；iPhone 实机视觉与耗电尚未实测。

导航、首屏和下载区均同时展示 iOS 公测与 Android 下载入口，两端按钮使用相同样式与尺寸。下载卡片在桌面端等宽，背景、边框、标题和按钮样式一致，移动端使用相同的卡片最小高度。

顶部导航与页脚的“加群获取支持”共用一个原生对话框，展示用户提供的微信群二维码。支持关闭按钮、Esc、点击遮罩关闭和保存图片，从手机菜单打开后关闭时焦点回到菜单按钮。窄于 1200 像素时导航收进菜单，避免新增入口挤压下载按钮。

二维码原图为 `assets/support-wechat-2026-11-05.png`，图片为 Whaleness 公测用户 2 群二维码，于 2026 年 11 月 5 日更新，注明 2026 年 11 月 12 日前有效。所有语言的项目 README 与产品页共用这张原图。更新群码时添加新的日期文件，并同步修改 `index.html` 中弹窗图片、保存链接与有效期描述，以及仓库根目录的 `README.md`、`README.en.md`、`README.zh-CN.md`，以及 `Docs/readme/` 中的所有其他语言 README 与本文中的图片路径和日期，再按现有 GitHub Pages 流程发布。

连接指南另外选用 7 张桌面端截图，位于 `assets/setup/`：桌面首页、插件列表、添加插件窗口、插件启用状态、网关设置、连接与配对页面、连接方式菜单。桌面截图保留原始比例，宽图优化至 1600 像素宽；添加窗口和连接方式菜单保留原始尺寸。

图文指南分为 6 个步骤，支持上一步、下一步、直接选择步骤和截图放大。同一步的多张截图通过按钮切换。最后一步展示生成二维码的操作入口，用户需在自己的桌面端生成配对码。

连接指南按当前屏幕宽度为最长说明、截图切换按钮和最长图注预留空间，各步骤切换时展示区域与上下步按钮位置保持固定。内容使用 240 毫秒交叉淡化，连续点击会立即切换目标步骤并取消上一段动画；启用“减少动态效果”时直接切换。

## 本地预览

可以直接用浏览器打开根目录的 `index.html`，或在仓库根目录启动本机预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765/`。页面下载入口分别使用 TestFlight 公测链接与 GitHub Releases 页面；桌面端与插件的安装说明见页面中的连接指南。
