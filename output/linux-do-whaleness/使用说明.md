# Whaleness Linux.do 分享素材

建议标题：做了个 DeepSeek Harness 原生移动客户端 Whaleness，支持 Android 和 iOS

- `Linux.do 发帖正文.md`：可复制到论坛编辑器。第一行用作标题，正文从“佬友们好”开始；图片使用公开仓库中固定提交的地址。
- `图文预览.html`：双击即可离线查看，截图全部内嵌；点击截图查看大图，按 Esc 或点击遮罩关闭。可以单独发送此 HTML 文件。
- `本地配图版.md` 和 `screenshots/`：若论坛不能加载外链图，把截图拖入发帖编辑器，替换对应图片链接。预览检查无误后再自行发布。
- `截图清单.json`：记录 19 张截图的仓库来源、尺寸和 SHA-256；截图保持原始内容和比例。

正文以已发布功能为范围，未纳入工作区中尚未发布的 1.7.13 更新项。公开发布页核对日期为 2026 年 10 月 30 日，显示最新版本为 1.7.12；帖子使用 Releases 总入口，不固定下载版本。

截图以 iOS 界面为主。团队、上传、语音、文字选择与存储截图来自 2026-10-22/23 素材；iPad 与 PDF 截图来自 2026-10-16 素材；Duo 宽屏截图来自 2026-10-26 模拟器素材。其他图片沿用项目 README 和产品页资源。未制作或伪造新功能截图。

此素材包仅用于预览和发帖准备，未代为发布到 Linux.do，也未更改仓库中的应用代码或版本文件。
