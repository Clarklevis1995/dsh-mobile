# 聊天数学公式兼容校验

## 本次问题

截图中的 `\sqrt[n]` 本身已支持；同一条公式中的 `\dfrac`、`\tag` 会触发 iOS 原生解析失败，导致整条公式显示源码。本次补上这些命令，并核对 Android 的对应差异。

## 可重复的校验范围

两端共享 `Tests/Fixtures/latex-math.json`，由 iOS 测试 bundle 与 Android androidTest assets 加载。共 321 条：

| 类别 | 数量 |
| --- | ---: |
| 渲染器注册的具名数学符号与数学样式 | 224 |
| 根号、分式、二项式、脚标、求和、积分、矩阵、分段、对齐、颜色、方框和编号等组合结构 | 44 |
| 字体命令 | 22 |
| 符号别名 | 13 |
| 重音命令 | 12 |
| 间距命令 | 6 |

每条都在行内/独立公式 × 黑/白文字四种配置下实际排版并检查非空像素，即每端 1284 个渲染组合。额外保留代码与链接隔离、未闭合流式内容、源码复制、基线、长公式横滑、深浅色截图等回归；iOS 还检查 dfrac/tfrac 的不同高度，以及 tag 出现在开头/结尾时编号位置一致。

这是一套明确的数学命令与组合回归，不等同于对所有可能的任意嵌套字符串做穷举证明。完整 LaTeX 文档命令、任意第三方宏包、文件导入、用户自定义宏环境不属于聊天公式的支持契约。未知指令或损坏输入仍显示源码，不静默删除运算内容。

## 实现

- iOS：扩展本地 SwiftMath 命令解析，显式分式样式采用局部节点；编号在数学式末尾显示，不覆盖或隐藏数字。
- Android：JLaTeXMath 已支持带次数的根号与显式分式。本次补齐编号、分组颜色、字体别名及 iOS 提供的额外字符别名，转换只发生在已识别的数学区域中。
- 编号随公式末尾显示；当前不实现整页文档级自动编号、跨公式引用或将编号固定到页面右页边。
