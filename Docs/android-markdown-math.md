# Android Markdown 数学公式

Android 正文使用 Markwon 解析 Markdown，数学部分使用 `ru.noties:jlatexmath-android:0.2.0` 在本地排版成透明位图，不依赖网页或网络服务。

## 解析与显示

- 支持行内 `\(…\)`、`$…$`，以及独立公式 `\[…\]`、`$$…$$`。
- 在 CommonMark 消费反斜杠之前，将公式保护成内部 `dsh-math` 图片节点；图片 visitor 识别后生成数学 span 或独立公式视图。
- 代码围栏、行内代码、缩进代码、链接目的地、图片说明、引用链接定义与转义美元保持原样。未闭合公式暂时显示原文，后续流式内容闭合后再渲染。
- 独立公式按自然尺寸横向滚动；行内公式通过 `ReplacementSpan` 使用数学引擎给出的基线、上伸和下伸尺寸，避免按图片底边对齐。
- `\boxed` 使用引擎的真实方框节点，支持分式、脚标、嵌套方框与极限；数学区域也兼容全角花括号。
- JLaTeXMath Android 0.2.0 绘制方框后会残留描边状态。`DshMathGraphics.drawChars` 单独使用填充画笔绘制文字，避免方框内字形空心；其他图形仍由原引擎绘制。
- 公式的长按操作使用已有 `DshPointMenu`，保留整条消息的复制、选择文字和回复。复制与选择时保护原公式的分隔符及反斜杠，不输出内部图片地址。

## 缓存与失败处理

- 引擎字体及宏表的访问串行化，透明位图按公式、显示模式、字号和颜色缓存，容量上限 16 MiB；视图再次进入可见区域时优先直接使用缓存。
- 独立公式在后台生成位图，按当前字体缩放和正文颜色显示，主题切换时使用对应缓存。
- 单条公式最多 8,000 字符；位图宽高上限分别为 16,384 / 4,096 像素，总像素不超过 4,194,304。未知指令或超出限制时显示 LaTeX 原文。

## 验证

`MarkdownMathDeviceTest` 覆盖：

1. 四种分隔符、引用公式、代码、链接、价格与未闭合流式内容。
2. 普通积分、分式、矩阵、分段函数、根号、嵌套方框和脚标的实际像素绘制，覆盖深浅色及行内/独立模式。
3. 行内基线及上下行高，防止公式被裁切。
4. 方框绘制前后的字形填充回归；修正前测试可复现失败。
5. 复制与选择保留公式源码、未知指令降级。
6. 正文实际视图深浅色截图、代码示例保持源码。
7. 长公式横向滑动。
8. 独立公式长按菜单及整条消息复制。

截图和设备测试日志保存在 `build/verification/android-math/`。同时回归已有 Markdown 正文、代码卡片和表格选择测试。
