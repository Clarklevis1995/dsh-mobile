# 文件改动审阅

设计稿：https://www.figma.com/design/bCMJxSi0tMpCt1MqKSiji9

- 文件改动胶囊位于输入框上方右侧，右边缘与输入框对齐，继续复用输入框材质。
- 手机一次显示一个文件。文件名按钮在原位弹出平台原生菜单（iOS Menu / Android PopupMenu），不进入新页面；选择、点击外部或返回时关闭菜单。
- 宽度小于 768 使用单列；768–1199 使用 248 宽目录；1200 起使用 260 宽目录。正文阅读宽度不超过 1000。
- 默认自动换行。一个逻辑行的行号、标记、正文共用实际高度，续行不重复行号。关闭换行后整个文件共用横向位移，行号固定。
- 每个 diff 片段使用 8 pt/dp 小圆角，标题与首尾内容按同一外轮廓裁剪；片段内部行及行号、正文交界保持连续，不给每行单独加圆角。开启和关闭换行时保持同一弧度。
- 换行使用纯图标按钮，点击在 `mdi:wrap` 与 `mdi:wrap-disabled` 间切换，不显示文字、对勾或背景块；两端图标均为 24，点击区域为 44，右侧位置固定。保留无障碍名称及开关状态。换行只更新正文布局，不重建面板或列表，不重置滚动状态。工具栏不显示「合并视图」。
- 当前文件显示 Host 绝对路径：平板在文件名下方，手机在文件选择工具栏下方；点击打开现有的完整文件预览，关闭后返回原 diff。路径展示由两端共享规则计算，读取仍使用协议原始路径并经过网关授权。完整预览读取当前文件，不把历史 diff 的片段拼接为完整文件。
- 删除行使用旧行号，其余使用新行号。协议前缀只在标记栏显示一次；缩进、空行和正文中的加减号保持原样。
- 文件切换清空旧内容，只显示与选中文件索引对应的响应。重新选中缓存文件可以即时恢复；迟到响应由共享状态机拒绝。
- 二进制、超限、记录过期、断线和认证失败分别展示明确状态，支持重试。Host 重启造成的历史 diff 不可用仍由网关决定。
- 文件图标复用 `FileIconCatalog` 与已确认的原始资源。界面使用同一份 Noto Sans SC，代码使用 JetBrains Mono，中文显式回退到 Noto Sans SC；字体及许可见 `Design/review-fonts`。

共享视觉规格位于 `WorkspaceChangesStyle`，行号、片段范围和省略上下文由 `WorkspaceReviewPresentation` 生成。文件选择菜单按用户要求使用平台原生实现；正文文字操作继续复用项目菜单。正文与目录在滚动边界隔离面板的剩余位移及惯性。

回归包括共享协议及展示测试、iOS `WorkspaceChangesViewTests` / `WorkspaceReviewUITests`、Android `WorkspaceChangesDeviceTest`。调试环境变量 `DSH_WORKSPACE_REVIEW_UI_TEST=1` 提供确定性的 iOS 布局测试数据，不修改连接配置或设备身份。

底部三个区域等宽排列，页数严格居中；“上一个文件 / 下一个文件”使用 16 号文字且不带箭头，页数使用 14 号文字。省略上下文只保留文字提示，不附加省略号；当前接口没有历史上下文，不提供展开。
