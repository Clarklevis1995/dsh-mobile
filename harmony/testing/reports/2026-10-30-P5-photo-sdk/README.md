# E24：实际图片与 Native 生命周期 SDK 专项

API21 ARM64 独立 smoke 包，最新 Native／HAP 构建成功。共享回归 99 项 JVM、43 项 Node 通过。

## 图片（P5-02a）

实际 TaskPool 执行生产 preparePhoto，读取自制 JPEG EXIF 1～8。逐项检查规范化后的宽高、四个象限真实像素颜色、输出 JPEG 文件大小与摘要形状；不是仅检查方向映射表。额外 4096×2730、方向 6 样本通过缩放，输出最长边不超过 2048px、文件不超过 1MiB。测试图不包含用户照片。

不包含实际系统相册选中、拍照、消息收发 G／D。

## Native 实例（P6-07a）

实际 NAPI 连续 32 轮创建／调用／显式释放／重复释放；释放后 dispatch 均拒绝，另一存活实例保持正常。用于源码中扫码验证器、主机移除与根页销毁的及时注册表释放。不替代多主机总内存预算与持久数据淘汰验收。
