# E34：实际 Window 旋转、深色与大字号

独立 API21 ARM64 包使用生产导航／输入器，通过实际窗口方向 API完成 1316×2832→2832×1316→1316×2832，聊天中英文及 emoji 草稿逐字保留。随后从生产设置页选择深色和 150% 应用字号，聊天输入与原生更多菜单可用。

仅测试副本增加 16vp 的全宽方向入口，生产源码无此入口。首版断言使用 UITest 布局宽度失败；实际原始截图证明转屏后已全宽，而 dumpLayout 会按旧竖屏宽度裁剪。最终以原始 PNG IHDR 验证真实方向，方向入口全宽以避免被旧坐标裁掉，保留草稿及菜单断言。没有为规避测试改变生产宽度。

属于手机旋转／大字号 F，截图为原始功能证据；不替代完整浅深页面 V、平板／折叠屏、系统物理字号和读屏 D。标题长文本按单行省略，完整草稿多行显示。
