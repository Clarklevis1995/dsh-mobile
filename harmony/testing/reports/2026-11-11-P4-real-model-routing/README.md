# 真实Host模型、思考等级与实际路由

2026-11-11，API21 ARM64独立smoke；真实Gateway 0.12.0、DSH 0.2.2-rc.1配置服务/会话/Agent/协议与生产Native、ArkUI。上游为本轮专属Host的受控本机模型，不请求外部LLM。只操作18897/18899和本轮临时DSH_HOME；未访问用户3080等网关。实际测试副本源码哈希另存。

通过：默认模型与High等级确认保存、取消不写、客户端冷启动重新读取；默认权限取消/确认；修改部署默认不改已启动会话。会话由产品内全部工作区、刷新与侧栏搜索定位，选择alternate/High后经权威接口确认、客户端冷启动读回。原生发送唯一标记，上游审计恰好一次收到指定provider/model/High，真实Host历史中用户与助手各一条精确标记，无重复执行；结束经原生UI恢复原模型、权限，并确认会话与新会话默认均恢复。

Host明确契约：dsh-api-session-controller/lib/index.js的selectModel先选择会话模型，随后agentDefaultModel.saveSelection异步尝试保存新会话默认值。网关只是delegate。旧“双向完全隔离”断言不符合此契约，保留失败记录，产品不自动回写旧默认；会话页说明此影响。默认配置页重新读取服务端实际值，不将当前会话的成功回执冒称全局后台持久化成功。

诊断保留：初始受控模型contextWindow=65536等于Host默认headroomTokens=65536，模型切换后触发真实上下文预算错误；测试适配器声明改为262144，不修改产品或Host压缩门禁。空草稿正常呈现语音入口，不能以message-send存在判断回复完成；改为上游审计+权威历史终帧断言。Host重启后专属观察器旧连接未恢复，另用校验PID/目录/端口的重启工具保存本轮会话归属并恢复；macOS /var与/private/var用realpath核对，不降低专属目录保护。

本记录不代表全页面V、全部模型供应商或真机完成。完整控制夹具回归单独追加。
