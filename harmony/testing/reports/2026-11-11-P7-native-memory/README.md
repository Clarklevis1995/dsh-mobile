# Kotlin/Native只读GC诊断

2026-11-11，API21 ARM64独立smoke，优化模式临时Native库。复制独立harmony工程到临时目录，共享源码只读引用；只在临时Native导出入口增加专用命令，读取GC.lastGCInfo、目标堆/上下限和定时间隔。未调用collect/schedule、未修改任何GC参数或Worker空闲时间、未制造系统内存压力。生产Native SHA在准备前后及本报告归档时逐字复核一致，独立无探针候选仍v6。

两轮1005历史/55274字符代码表格流、精确终帧长度/FNV、草稿/锚点/前后台功能断言通过。诊断模式明确acceptanceEligible=false且只输出DIAGNOSTIC_ONLY，不调用性能验收passed；所有冻结阈值仍保留。新增的只读NAPI统计本身有采样开销，不是正式性能或优化收益结论。

首次编译要求同时显式opt-in NativeRuntimeApi和ExperimentalStdlibApi，补齐后实际Native优化编译和HAP通过；新增测试Kotlin文件ktlint先发现1处多行表达式格式，格式化后通过。实际已编译探针快照/哈希单独保存，之后根测试模板仅有该格式修正。探针注入有生产目录/测试bundle保护；生产目录拒绝注入且Index字节不变的检查通过。原始Native编译器产生大量既有生成C++警告，仅归档任务/成功摘要；首个API错误按文件过滤，不收录冗长命令行。

本轮不关闭P7-06b、全页面V或真机验收。测试smoke、临时夹具和新增映射finally清理；正式包与候选包未覆盖。
