# 回复图标

- Android：使用与 iOS 同名的 `arrowshape.turn.up.left` Regular 轮廓，经 Figma 转为矢量路径，24 × 24 视口，显示为 16dp。
- 当前源文件：`reply-ios.svg`；Figma 组件：https://www.figma.com/design/Dvs7ruDuthX1vtF1rDQyFc?node-id=71-212 。
- `ic_message_reply.xml` 保留矢量内部的中空轮廓，颜色由 Compose 主题 tint 控制，并支持 RTL 自动镜像。
- 历史 Lucide 图标来源：https://lucide.dev/icons/reply ，下载：https://unpkg.com/lucide-static@0.468.0/icons/reply.svg 。其 ISC 许可见 LICENSE。
- iOS：原生 SF Symbol `arrowshape.turn.up.left`，显示为 16pt。
- 放在助手消息底部的复制按钮右侧，颜色跟随系统主题。
- 历史 Lucide 源文件 `reply.svg` 的 SHA-256：`5aa9a4ae2239acdd20268a19aed53790090ca4bf094477b560255dd3b027f2aa`；原下载地址及 ISC 许可仅对应此历史文件。
