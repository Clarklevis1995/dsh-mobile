# 链接图标

采用 Figma Simple Design System 的 Link，画布 24×24，2 单位线宽，圆形端点与连接。

- Figma 组件：https://www.figma.com/design/Dvs7ruDuthX1vtF1rDQyFc?node-id=35-191
- Figma 预览：https://www.figma.com/design/Dvs7ruDuthX1vtF1rDQyFc?node-id=35-194
- Android：`androidApp/src/main/res/drawable/ic_link.xml`

Android VectorDrawable 保留 SVG 的路径、线宽和裁切区域，由使用处进行模板着色。
