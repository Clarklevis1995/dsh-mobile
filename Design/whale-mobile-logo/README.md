# 鲸鱼手机 Logo

## 文件

- `whale-mobile.svg`：512 × 512 画布，透明背景，纯黑白矢量主稿。
- `whale-mobile-preview.png`：1024 × 1024 白底预览。

## 原稿位置

- iOS：`DeepSeekHarnessMobile/Resources/Assets.xcassets/DeepSeekWhale.imageset/deepseek-whale.svg`
- Android：`androidApp/src/main/res/drawable/deepseek_whale.xml`

主稿沿用原始 SVG 的外轮廓路径，保留上翘尾巴、头顶小鳍和圆润身体。白色腹部延续原图的斜向走势；双眼朝向观者，胸鳍环抱略微倾斜的手机。手机使用简洁屏幕、顶部听筒和底部横条，保证物体辨识度。

SVG 中所有图形均为可编辑的路径或几何元素，没有嵌入位图、外部资源、字体、渐变或滤镜。`whale`、`face`、`phone` 和 `holding-flipper` 分别标记主要元素。白色是图形的一部分，画布背景透明。

本次仅交付设计素材，没有替换应用内的现有图标。
