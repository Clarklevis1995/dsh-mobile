# 文件改动审阅图标

- 自动换行：Material Design Icons `mdi:wrap`。
- 不自动换行：Material Design Icons `mdi:wrap-disabled`。
- Figma 设计来源：https://www.figma.com/design/bCMJxSi0tMpCt1MqKSiji9?node-id=25-632 ，图标节点分别为 `25:636`、`25:641`。
- 当前目录保存 Figma 导出的原始 SVG，原始画布为 40 × 40；应用显示为 24 × 24，保留完整图形比例，点击区域为 44 × 44。
- iOS 使用同源 SVG 的模板图片，Android 使用同一 SVG 转换的 VectorDrawable；颜色沿用审阅页的开启蓝色与关闭次要色。
- 作者与许可：https://pictogrammers.com/library/mdi/ ，见本目录许可文件。两端应用资源中保留许可副本。
